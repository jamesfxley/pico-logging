# Standing deviations

Scope-wide suppressions require review under EN-00.5 and count against the
per-language ceiling under EN-00.6.

| Check | Scope | Rationale | Risk and mitigation | Approval | Review by |
|---|---|---|---|---|---|
| readability-magic-numbers | tests/ | EN-04.7, the exemption CXX-02.8 names explicitly. A literal size, level or count in a test is the case under test, not a value shared with production code; hoisting it to a named constant moves the expected value away from the assertion that reads it. The library owns the overlay at `tests/.clang-tidy`. | A wrong expected value can agree with a defect in the implementation. Assertions compare behavior with the literal; review checks the expected value against the requirement or protocol, and other enabled checks remain active. | approved by the maintainer, 2026-10-29 | 2027-04-13 |
| misc-include-cleaner | tests/docs/ | EN-03.5. Each harness here and the `.inc` its document generates are one translation unit split across two files by design: the harness supplies the includes and stubs, the `.inc` holds the example. The check reads each file's includes against that file's own uses, so every include a harness makes for its example reads as unused, and keeping them is the only way the example compiles. | An include a harness genuinely no longer needs stays. Bounded by the scope being harnesses only, each a few lines that `house_cxx_add_doc_examples` refuses unless it pairs with an example, and by every other check still applying to them. | approved by the maintainer, 2026-10-29 | 2027-04-13 |
| misc-use-internal-linkage | tests/docs/ | EN-03.5. The functions an example defines are a reader's code, with the external linkage a reader's code has; making them `static` or anonymous would show the reader a different program from the one they write, and an unused internal function is then a `-Wunused-function` error under the strict flags. | A function in a harness that should have been internal is not reported. Bounded by the scope holding only harnesses and the examples they include, none of which ships or is linked into anything. | approved by the maintainer, 2026-10-29 | 2027-04-13 |
